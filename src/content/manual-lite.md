# 1. 시작하기 전에

## 1.1 이 문서에 대하여

이 문서는 **부엉이 트레이더 라이트 (Owl Trader Light)** 의 공식 사용자 설명서입니다. 라이트 버전은 **키움증권 REST API 기반의 조건검색식 자동매매**에 집중한 경량 프로그램입니다.

부엉이 트레이더 프로와 달리 AI 분석·차트·서버 연동을 제외하고, 조건검색식으로 매수하고 손절·익절·트레일링 스탑·분할 매매 등 계좌를 지키는 매도 전략에 집중했습니다.

### 적용 버전

| 항목 | 내용 |
|---|---|
| **프로그램명** | 부엉이 트레이더 라이트 |
| **문서 적용 버전** | 1.5.1 |
| **운영체제** | Windows 10 이상 (64비트) |
| **필수 연동** | 키움증권 REST API |

⚠️ **주의:** 사용 중인 프로그램 버전과 이 문서의 적용 버전이 다르면 화면 구성이나 기능이 다를 수 있습니다.

## 1.2 동작 원리

라이트 버전의 자동매매는 다음 흐름으로 동작합니다.

*   키움 HTS(영웅문)에서 미리 만들어 둔 **조건검색식**이 종목을 포착합니다.
*   포착된 종목을 전략에 연결된 **매매 설정 프로필**에 따라 매수합니다.
*   보유 종목은 손절·익절·트레일링 스탑·분할 매도 규칙에 따라 자동으로 청산됩니다.

> ⚠️ 조건검색식은 **키움 HTS에서 먼저 생성**해야 프로그램의 전략 설정 목록에 나타납니다.

## 1.3 사용 전 알아둘 점

| 항목 | 내용 |
|---|---|
| **증권사 API** | 키움증권 REST API (단일 연동) |
| **AppKey 발급 단위** | 계좌번호별로 발급하며, 계좌와 AppKey는 1:1로 대응합니다. |
| **키움 접속 단절 시간** | 월~토 07:50~07:55, 일 05:00~05:15 (해당 시간에는 접속·주문 불가) |
| **초기 모의투자 기간** | 설치 후 **7일간**은 모의투자 사용을 권장합니다. 강제는 아니며, 이 기간에도 실전투자 계좌를 등록할 수 있습니다(안내 배너와 저장 시 확인 창이 표시됩니다). |


# 2. 설치 및 계좌 등록

## 2.1 프로그램 설치

*   설치 파일 **`OwlTraderLight-Setup.exe`** 를 실행합니다. .NET Desktop Runtime 10(x64)이 없으면 자동으로 감지하여 함께 설치합니다.
*   **사용권 계약(License)** 에 동의하면 설치가 진행됩니다.
*   기본 설치 경로는 `%ProgramFiles%\SageLine\OwlTraderLight`이며, 시작 메뉴와 바탕화면에 바로가기가 생성됩니다.

## 2.2 계좌 등록 (AppKey / SecretKey)

![계좌 AppKey 설정 화면](/images/manual-lite/account-key-setting.png)

라이트 버전은 별도의 아이디·비밀번호 로그인이 아니라 **계좌별 API 키 등록** 방식으로 인증합니다. **계좌현황** 패널의 API 키 설정에서 등록합니다.

계좌 AppKey 설정 창은 **계좌 목록(좌) · 계좌 정보(중앙) · 주문 폭주 방지 하드 리밋(우)** 3열로 구성됩니다.

| 입력 항목 | 내용 |
|---|---|
| **모의투자 계좌 여부** | 모의투자 환경에서 거래할 경우 체크합니다. 연결 테스트가 접속할 서버(실서버/모의서버)를 결정하므로 **가장 먼저** 선택합니다. |
| **계좌번호** | 8자리 계좌번호 |
| **계좌명** | 구분하기 쉬운 이름 |
| **AppKey / SecretKey** | 키움에서 발급받은 REST API 키 |

*   **연결 테스트** 버튼으로 키를 실시간 검증할 수 있으며, 저장 시 다시 한 번 검증합니다.
*   설치 후 7일 이내에는 창 상단에 **모의투자 권장 안내**가 표시되고, 실전투자 계좌를 저장할 때 확인 창이 한 번 더 뜹니다.

📌 **참고:** 예전에 있던 **기본 수동매수 전략** 항목은 없어졌습니다. 외부에서 매수한 종목을 어느 전략으로 관리할지는 미리 정해 두는 대신, 종목을 자동매매에 넣는 그 자리에서 고르도록 바뀌었습니다. (4.3 참조)

## 2.3 주문 폭주 방지 하드 리밋 (계좌별)

자동매매 오작동으로 인한 무한 매수·매도를 막는 최종 안전장치입니다. 상한값은 **계좌마다 다르게** 지정하며, 계좌 AppKey 설정 창 오른쪽 패널에서 편집합니다.

| 항목 | 내용 |
|---|---|
| **일일 매수 한도 (회)** | 계좌 전체 기준, 하루 매수 주문 횟수 상한 |
| **일일 매도 한도 (회)** | 하루 매도 주문 횟수 상한. 청산이 막히지 않도록 여유 있게 설정하십시오. |
| **종목별 일일 매수 한도 (회)** | 동일 종목에 대한 하루 매수 주문 횟수 상한 |
| **1회 주문 최대 금액 (만원)** | 주문 1건(수량 × 가격)의 최대 금액 |
| **일일 매수 금액 한도 (만원)** | 하루 누적 매수 주문 금액의 총 상한 |
| **잔고 최대 종목수 제한 (종목)** | 계좌 잔고가 이 종목 수에 도달하면 자동매매의 **신규 진입만** 거절합니다. (기본 100종목) |

> 값 **0은 무제한**입니다.

### 금액은 만원 단위로 입력합니다

**1회 주문 최대 금액**과 **일일 매수 금액 한도**는 **만원 단위**로 입력합니다. 예를 들어 `1,000` 은 1,000만원입니다. 입력란 오른쪽에 환산 금액(`= 10,000,000원`)이 항상 표시됩니다.

💡 **왜 만원 단위인가:** 천만·억 단위를 원으로 입력하면 0의 개수를 세다 자릿수를 한 자리 틀리기 쉽고, 그 실수가 곧 주문 상한 10배 차이가 되기 때문입니다. **저장된 값과 실제 차단 기준은 종전과 같습니다.** 화면에서 받는 단위만 바뀌었고, 쓰시던 설정은 자동으로 환산되어 표시됩니다.

### 잔고 최대 종목수 제한

보유 종목 수 상한은 예전에 전략마다 두었으나, **계좌 단위로 옮겨졌습니다.** 위험은 계좌 단위로 생기는데 상한을 전략마다 두면 계좌 전체가 몇 종목을 들고 있는지는 아무도 보지 않게 되기 때문입니다.

| 항목 | 동작 |
|---|---|
| **세는 기준** | **계좌 잔고 전체.** 이 프로그램이 산 종목뿐 아니라 HTS 등 밖에서 산 종목도 함께 셉니다. |
| **막히는 것** | 자동매매의 **신규 종목 진입만** 거절됩니다. |
| **막히지 않는 것** | 보유 종목의 추가 매수(물타기·불타기), 매도, 직접 내는 수동 매수 |
| **경고** | 잔고 종목 수가 상한의 **80%** 를 넘으면 계좌현황에 경고 줄이 나타납니다. |

⚠️ **주의:** 기존 계좌도 **100종목**으로 설정된 상태로 올라옵니다. 종전 전략별 상한(기본 10종목)보다 훨씬 느슨하므로, **종전과 같이 운용하려면 계좌 설정에서 값을 낮춰 주십시오.**

> **하드 리밋 활성화**, **반복 주문 한도**, **이상 시세 가드**는 계좌 공통 설정이므로 시스템 설정(9.1)에서 관리합니다.


# 3. 시작 가이드 (최초 실행)

프로그램을 처음 실행하면 **시작 가이드(온보딩 위저드)** 가 표시됩니다. 다음 3단계를 순서대로 진행하면 자동매매 준비가 완료됩니다.

*   **1단계 — 계좌 등록**: AppKey/SecretKey를 등록합니다. (2장 참조)
*   **2단계 — 매매 설정 프로필 확인**: 매수·매도 규칙이 담긴 프로필을 확인합니다. (6장 참조)
*   **3단계 — 전략 생성**: 계좌·조건검색식·프로필을 연결해 전략을 만듭니다. (5장 참조)

선택적으로 텔레그램 알림, 실행 스케줄, 주문 하드리밋(계좌별 상한은 2.3 참조)을 함께 설정할 수 있습니다. "다시 표시하지 않음"을 선택하면 다음 실행부터 표시되지 않습니다.

📌 **참고:** 키움 서버 점검 시간(11.2)에 프로그램을 시작하면 연결 지연 안내 창이 뜨고, **점검 종료까지 남은 시간이 실시간으로 표시**됩니다.


# 4. 메인 화면 둘러보기

메인 화면은 상단 메뉴바, 3열 본문, 하단 로그·상태바로 구성됩니다.

![부엉이 트레이더 라이트 메인 화면](/images/manual-lite/main-overview.png)

📌 **참고:** 좌측(계좌현황·매매 전략 목록)과 우측(실시간 체결 현황) 패널은 **접을 수 있습니다.** 접으면 그 자리에 세로 막대가 남고, 막대를 누르면 다시 펼쳐집니다(≪ ≫ 버튼). 실시간 체결 현황은 **기본 접힘**이라 보유 종목 목록이 더 넓게 보입니다.

## 4.1 계좌현황 패널 (좌측)

총자산(추정 예탁)·주문가능금액·**총매입**·**총평가**·총평가손익·계좌 수익률을 보여줍니다. 새로고침 버튼과 API 키 설정 진입 버튼이 있습니다.

| 항목 | 내용 |
|---|---|
| **총매입** | 보유 종목에 투입한 원금 |
| **총평가** | 현재 시세 기준 평가액. 평가손익과 항상 맞아떨어지도록 계산됩니다. |
| **주문가능금액** | **D+2 현금 주문가능금액** 기준이며 60초마다 자동 갱신됩니다. |

**계좌번호 마스킹** — 화면에 표시되는 계좌번호는 가운데가 가려진 형태(`81****95`)로 나옵니다. 방송·화면 공유 시 노출을 막기 위한 것으로 **기본 켜짐**이며, 시스템 설정에서 끌 수 있습니다. 주문·조회 등 내부 동작은 항상 원본 계좌번호를 사용합니다.

**한도 경고** — 예전에 늘 붙어 있던 "당일 주문" 줄은 없어졌습니다. 대신 일일 주문 한도의 **80% 이상을 사용했을 때만** 주황색 경고가 나타납니다. 경고가 보이면 곧 주문이 자동 거부될 수 있다는 뜻입니다. 잔고 종목 수가 상한의 80%를 넘을 때도 같은 자리에 경고가 나타납니다. (한도 조정은 2.3)

## 4.2 매매 전략 목록 패널 (좌측)

등록한 전략이 카드로 표시됩니다. 카드의 **가동/정지 토글**로 개별 전략을 켜고 끌 수 있고, **일괄 실행 / 일괄 중지** 버튼과 **신규 전략 등록** 버튼을 제공합니다. 카드에는 **적용 계좌**가 함께 표시됩니다.

📌 **참고:** 전략 이름은 **기본으로 숨겨져 있습니다.** 조건식·설정 프로필·계좌만으로도 전략을 구분할 수 있기 때문이며, 카드에 마우스를 올리면 툴팁으로 표시됩니다. 항상 보이게 하려면 [시스템 설정 → 표시]에서 켜십시오.

## 4.3 실시간 보유 종목 감시 (중앙)

보유 종목의 종목명·평균단가·현재가·수익률·평가손익·분할 진행 단계·상태를 실시간으로 보여줍니다. 자주 보는 정보(상태 → 전략 → 종목명 → 평가손익 → 수익률)가 왼쪽에 오도록 배치되어 있습니다.

![실시간 보유 종목 감시 및 체결 현황](/images/manual-lite/monitoring-holdings.png)

계좌가 여러 개라면 **계좌 필터**로 특정 계좌의 종목만 볼 수 있습니다.

### 4.3.1 외부에서 매수한 종목 — "외부보유"

HTS 등 이 프로그램 밖에서 매수한 종목은 감시 목록에 **"외부보유"** 로 표시만 되고, **자동매매 대상이 되지 않습니다.**

⚠️ **예전에는 자동으로 편입되었습니다.** 장기 보유 목적으로 산 종목이 손절선에 걸려 바로 팔릴 수 있는 위험이 있어 바뀌었습니다.

자동매매에 넣으려면 종목을 선택하고 **우클릭 → [선택 종목 자동매매 편입]** 을 실행합니다.

*   편입할 때 **어느 전략으로 관리할지 그 자리에서 고릅니다.**
*   선택한 전략의 손절률·당일청산 등 **실제로 걸리는 감시 내용을 확인 창에서 보여 줍니다.**
*   외부보유 종목을 목록에 아예 표시하지 않으려면 [시스템 설정 → 매매]의 **하이브리드 모드**를 끄십시오. 다만 그 경우 해당 종목은 직접 관리해야 합니다.

### 4.3.2 종목별 자동매매 일시중지

갑작스러운 악재·호재가 있을 때 특정 종목의 자동매매만 잠시 멈출 수 있습니다.

*   종목을 체크하고 **우클릭 → [선택 종목 자동매매 중지]**
*   되돌릴 때는 같은 메뉴의 **[선택 종목 자동매매 재개]**
*   프로그램을 껐다 켜도 중지 상태는 유지됩니다.

⚠️ **주의:** 중지 중에는 매수뿐 아니라 **손절·익절·당일청산도 함께 멈춥니다.** 재개 전까지는 자동 보호가 없습니다. 보유 주식은 그대로 유지되고 직접 매도는 언제든 가능합니다.

### 4.3.3 상태 배지 읽는 법

| 배지 | 의미 | 재개 |
|---|---|---|
| 🟠 **일시중지** (주황) | 사용자가 직접 멈춘 상태 (4.3.2) | 가능 |
| 🔴 **매매중지** (빨강) | 액면분할 등 **권리이벤트로 시스템이 멈춘** 상태 (8장) | **불가** |
| **⚠ 경고 아이콘** | 전일종가와 기준가가 다른 종목(배당락 등 소폭 조정). 표시만 하고 매매는 계속합니다. | — |
| **외부보유** | 이 프로그램 밖에서 매수한 종목 (4.3.1) | — |

📌 **참고:** 우클릭 메뉴의 **[선택 종목 삭제]** 는 **기본으로 숨겨져 있습니다.** 실제 매도가 아니라 감시 목록에서만 빼는 기능이지만, 보유 종목에 실행하면 손절·익절 등 자동 감시가 중단되기 때문입니다. 오류 종목 정리처럼 꼭 필요할 때만 [시스템 설정 → 표시]에서 켜십시오.

📌 **참고:** 매수 주문이 하루 종일 한 주도 체결되지 않으면 수량 0인 기록이 남는데, 다음 날 프로그램 시작 시 **자동으로 정리**됩니다. 보유 중이거나 주문이 걸려 있는 종목은 건드리지 않습니다.

## 4.4 실시간 체결 현황 (우측)

시간·계좌·종목·구분·체결 수량/단가/금액을 실시간으로 표시합니다.

**구분** 열은 이 체결이 어디서 나온 것인지 보여 줍니다 — "자동 매도", "수동 매도", "외부 매수"처럼 표시되며, 자동매매가 낸 것인지, 프로그램에서 직접 낸 것인지, HTS 등 밖에서 낸 것인지 구분됩니다. 프로그램을 다시 켜도 유지됩니다.

## 4.5 상단 지수 · 로그 · 실시간 등록 현황

### 4.5.1 상단 지수 표시

화면 맨 위에 띄울 지수를 **직접 고를 수 있습니다.** [시스템 설정 → 표시]에서 선택하며, **개수 제한은 없습니다.**

| 구분 | 선택할 수 있는 항목 |
|---|---|
| **국내 업종지수** | KOSPI · KOSDAQ · KOSPI200 · KRX100 · 대형주 · 중형주 · 소형주 |
| **해외 참고 지표** | 나스닥 · S&P500 · 원·달러 환율 · WTI 유가 |

*   기본값은 국내 **KOSPI · KOSDAQ** 이고, **해외 지표는 4종 모두 켜져 있습니다.**
*   저장 즉시 반영되며 재시작이 필요 없습니다.
*   3개 이상 켜면 등락 표기가 퍼센트만으로 짧아지고, 등락폭은 칩에 마우스를 올리면 툴팁으로 보입니다.
*   장 시간 밖에도 국내 지수의 등락이 표시됩니다. 마지막 거래일 기준이며, 어느 날 기준인지는 툴팁에 적힙니다.

⚠️ **해외 지표는 외부 서비스에서 가져옵니다.** 키움 API는 국내주식 전용이라 해외지수·환율·유가를 제공하지 않습니다. 그래서 이 값들만은 **외부 공개 데이터(야후 파이낸스)를 1분마다 조회해** 채웁니다.

| 항목 | 내용 |
|---|---|
| **통신** | 이 PC에서 해당 서비스로 조회가 나갑니다. **보내는 정보는 없습니다.** |
| **용도** | **표시 전용입니다.** 자동매매 판단에는 전혀 쓰이지 않습니다. |
| **지연 표시** | 값이 **5분 넘게 갱신되지 않으면 칩이 흐려집니다.** 멈춘 숫자를 현재가로 읽지 않도록 하기 위한 표시입니다. |
| **끄는 방법** | [시스템 설정 → 표시]에서 **해외 지표를 모두 끄면 조회 자체가 멈춥니다.** |

국내 지수 칩과는 이름 색으로 구분되며, 칩에 마우스를 올리면 출처와 갱신 시각이 나옵니다.

📌 **참고:** 자주 요청 주시는 **코스피 야간선물은 넣지 못했습니다.** 키움 API에 파생상품 시세가 없고, 무료 공개 출처에도 해당 계약이 없습니다.

### 4.5.2 로그 · 실시간 등록 현황

*   하단 **로그 패널**(기본 접힘)에 실시간 거래·시스템 이벤트가 기록됩니다.
*   하단 **실시간 등록 현황** 상태바에 계좌별 시세·조건 실시간 등록 건수가 표시되며, 클릭하면 요청 제한 안내 팝업(체결 최대 100건, 조건검색 최대 10건 등)을 볼 수 있습니다.


# 5. 매매 전략 설정

전략은 **"계좌 + 매수 조건검색식 + 매매 설정 프로필"** 의 연결입니다. 매매 파라미터 본체는 프로필(6장)에 있고, 전략에서는 어떤 조건식으로 매수하고 어떤 프로필을 적용할지 지정합니다.

## 5.1 전략 만들기

전략 목록 패널의 **신규 전략 등록**에서 전략 설정 창을 엽니다.

*   **적용 계좌**를 선택하면 해당 계좌의 조건검색식이 실시간으로 불러와집니다.
*   **매수 조건검색식**을 선택합니다.
*   적용할 **매매 설정 프로필**을 선택합니다. (필요 시 프로필 관리로 이동)

📌 **참고:** **전략 이름은 매수 조건검색식 이름을 자동으로 따릅니다.** 직접 입력하려면 고급 설정에서 바꿀 수 있습니다.

⚠️ **최대 보유 종목 수 항목은 없어졌습니다.** 보유 종목 상한은 계좌 단위로 옮겨졌습니다. **계좌 AppKey 설정**의 **잔고 최대 종목수 제한**에서 지정하십시오. (2.3 참조)

## 5.2 전략 수정 · 삭제

전략 목록 카드에서 수정하거나 삭제할 수 있습니다.


# 6. 매매 설정 프로필

매매 설정 프로필은 매수·매도·분할 규칙을 담는 **4개 탭**으로 구성됩니다. 하나의 프로필을 여러 전략·계좌에 적용할 수 있습니다.

⚠️ **예전의 "기타 설정" 탭은 없어졌습니다.** 당일 청산·재매수 제한·미체결 자동 취소는 **[시스템 설정 → 매매]** 로 옮겨져 **모든 전략에 공통 적용**됩니다. 자세한 내용과 주의사항은 9.1을 참고하십시오.

## 6.1 매수 & 필수 설정 (탭 1)

![매매 설정 프로필 — 매수 및 필수 설정 탭](/images/manual-lite/profile-buy.png)

| 항목 | 내용 |
|---|---|
| **주문 종류** | 지정가 / 시장가 |
| **가격 구분** | 상한가·현재가·하한가·시가·고가·저가 중 선택 |
| **호가 조정** | 기준 가격에서 호가 단위만큼 가감 |
| **종목당 투자액** | 한 종목에 배정할 금액 |
| **거래 시간 제한** | 장 운영시간(09:00~15:18) 또는 사용자 지정 시간 |

⚠️ **프리·애프터마켓 주문은 지정가로 나갑니다.** 프리마켓(08:00~08:50)·애프터마켓(15:40~20:00)은 정규장 밖이라 시장가 주문이 불가능하고, 거래도 적어 불리한 가격에 체결될 수 있습니다. 시장가로 설정해도 **지정가(매수 10호가 / 매도 -10호가)** 로 변환되어 전송됩니다. 변환 방식은 [시스템 설정 → 매매]에서 바꿀 수 있습니다.

## 6.2 매도 & 청산 설정 (탭 2)

![매매 설정 프로필 — 매도 및 청산 설정 탭](/images/manual-lite/profile-sell.png)

| 항목 | 내용 |
|---|---|
| **손실 제한(손절)** | 기본 3%. 지정 손실률 도달 시 매도 |
| **이익 실현(익절)** | 기본 5%. 지정 수익률 도달 시 매도 |
| **이익 보존** | 확보한 이익이 일정 수준 이하로 줄면 매도 |
| **트레일링 스탑** | 발동 기준가 대비 %로 활성화한 뒤, 최고가 대비 % 하락 시 매도 |
| **매도 조건식 (익절용)** | 매입단가 대비 지정 % **이상 상승**한 상태에서 이 조건식 신호가 오면 전량 매도 |
| **매도 조건식 (손절용)** | 매입단가 대비 지정 % **이상 하락**한 상태에서 이 조건식 신호가 오면 전량 매도 |

⚠️ **익절용·손절용은 조건식 신호만으로 팔지 않습니다.** 매입단가 대비 지정 비율에 도달했을 때만 전량 매도하며, 시세를 아직 받지 못한 종목에서는 발동하지 않습니다.

📌 **참고:** 예전의 **매도 조건식 감시**(수익률과 무관하게 신호만으로 전량 매도)는 **기본으로 숨겨져 있습니다.** 보통은 위의 익절용·손절용 조건식으로 충분하기 때문입니다. 이미 사용 중인 프로필에서는 자동으로 표시되어 확인·해제할 수 있고, 새로 쓰려면 [시스템 설정 → 표시]에서 켜십시오.

## 6.3 분할 매수 (탭 3)

![매매 설정 프로필 — 분할 매매 탭](/images/manual-lite/profile-split.png)

배정 방식(금액/비율)과 단계별 **하락률**·배정비율을 지정합니다. 최초 매수 진입 단계를 포함합니다.

## 6.4 분할 매도 (탭 4)

단계별 **상승률**·매도비율을 지정합니다.

### 분할 매매 입력 규칙 (탭 3 · 4 공통)

*   입력 칸은 **숫자만** 받습니다. 값은 항상 **부호 없이 양수**로 입력합니다.
*   표 머리글에 방향이 표시됩니다 — **`▼ 하락률 (%)`** / **`▲ 상승률 (%)`**
*   잘못된 값은 입력하는 즉시 칸이 붉게 표시됩니다.

📌 **참고:** 단계별 **조건검색식 열은 기본으로 숨겨져 있습니다.** 분할 단계는 대부분 등락률·손익률만으로 운용하기 때문입니다. 숨겨도 이미 저장한 조건검색식은 그대로 적용되며, 확인하거나 바꾸려면 [시스템 설정 → 표시]에서 켜십시오.

⚠️ **매도 체결을 기다리는 동안에는 추가 매수가 나가지 않습니다.** 예전에는 손절·익절 매도 주문을 낸 뒤 체결을 기다리는 사이 같은 종목에 물타기가 발동할 수 있었습니다. 손실을 확정하려는 종목을 오히려 더 사는 상황이라 막았습니다.

> 프로필 기본값: 시장가 5단계 분할 매수(-3/-5/-7/-10/-15%), 손절 3%·익절 5% 활성(트레일링·분할 매도 비활성).


# 7. 조건검색 신호

## 7.1 조건검색 시세 기준 (KRX+NXT 통합시세)

조건검색은 **통합시세(KRX+NXT) 기준**으로 동작합니다.

이 프로그램은 시세도 주문도 통합시세 기준인데 조건검색만 KRX 단독이었습니다. 그래서 NXT만 열리는 프리마켓(08:00~08:50)·애프터마켓(15:40~20:00)에는 **주문은 NXT로 나가면서 정작 진입 신호가 나오지 않았고**, 정규장에서도 KRX와 통합 가격의 차이만큼 신호 시점이 어긋났습니다.

⚠️ **기존 사용자도 함께 전환되었습니다.** 조건검색 신호가 나오는 **시점과 개수가 종전과 달라질 수 있습니다.**

| 항목 | 내용 |
|---|---|
| **되돌리는 방법** | [시스템 설정 → 매매]의 **조건검색 시세 기준**에서 `KRX 시세` 선택 |
| **적용 시점** | **프로그램을 다시 켜야 적용됩니다.** |
| **모의투자 계좌** | 통합시세를 지원하지 않아 선택과 무관하게 항상 KRX 기준으로 동작합니다. |
| **자동 전환** | 서버가 통합시세 검색을 거부하면 자동으로 KRX 기준으로 전환해 등록합니다. |

## 7.2 조건검색 신호 모니터

조건검색식·종목별 당일 수신 건수와 포착·편입·이탈 신호를 실시간으로 보여줍니다. 신호 이력(검색 종류, 매수/매도 구분, 생성 시각)도 확인할 수 있습니다.

## 7.3 가상 신호 생성기 (테스트용)

실거래 없이 자동매매 로직을 검증하는 테스트 도구입니다. **편입/이탈 신호**(계좌·전략·종목 지정)와 **포착 신호(다중)**(종목코드 목록)를 임의로 발생시켜 전략이 정상 동작하는지 확인할 수 있습니다.

⚠️ **메뉴에 보이게 하려면 [시스템 설정 → 데이터·진단]의 테스트 모드를 켜야 합니다.** 가상 신호는 **실제 주문으로 이어질 수 있으므로** 실매매 중에는 해제해 두십시오.


# 8. 권리이벤트 감지와 자동매매 중지

액면분할·병합, 무상·유상증자, 배당락 같은 **권리이벤트**가 발생하면 기준가가 전일종가와 달라집니다. 이때 보유 포지션의 평균단가·최고가는 변경 전 가격 기준으로 남아 있어, 손절·익절·트레일링 스탑이 잘못된 기준으로 오발동할 수 있습니다. 프로그램은 이를 감지해 경고하거나 해당 종목의 자동매매를 중지합니다.

## 8.1 감지 시점

*   프로그램 시작 시(보유 종목 시세 구독 이후) 1회 비교합니다.
*   이후 매일 **종목정보 캐시 새로고침 시각**(기본 07:40, 시스템 설정에서 변경)에 캐시를 갱신하고 다시 비교합니다.
*   활성 전략의 감시 대상 종목만 검사하며, 추가 API 요청 없이 기존 조회 데이터를 재사용합니다.

## 8.2 경고 표시 (소폭 조정)

괴리율이 임계값 미만이면 감시 화면 종목명 옆에 **⚠ 아이콘**만 표시하고 자동매매는 그대로 진행합니다. 툴팁에서 전일종가·기준가·괴리율을 확인할 수 있습니다.

## 8.3 자동매매 중지 (대폭 조정)

괴리율이 **자동매매 중지 괴리율**(기본 30%, 시스템 설정에서 변경) 이상이면 해당 종목의 자동매매를 중지하고 🔴 **매매중지** 배지를 표시합니다. 중지는 종목 단위로 적용되며 계좌를 가리지 않습니다.

| 구분 | 내용 |
|---|---|
| **차단되는 동작** | 손절·익절·트레일링 스탑·분할 매매, 당일 청산, 조건검색식에 의한 신규 진입·매수·매도 |
| **유지되는 동작** | 실시간 시세 수신(현재가·평가손익 확인), 사용자의 수동 매도 |
| **알림** | 최초 중지 시 팝업·로그·텔레그램 알림을 발행합니다. (매일 재판정으로 중복 알림되지 않습니다) |

📌 **참고:** 괴리율을 **0으로 입력하면 중지하지 않고 ⚠ 경고만** 표시합니다.

## 8.4 중지된 종목 정리

*   중지 상태는 저장되어 **프로그램을 재시작해도 유지**됩니다. 재시작 시 중지 종목을 묶은 요약 안내가 1회 표시됩니다.
*   권리락 다음 날부터는 전일종가와 기준가가 다시 일치하지만, 중지 종목의 ⚠ 경고와 사유 툴팁은 그대로 유지됩니다.
*   보유 수량은 그대로 남아 있습니다. 정리는 **보유종목 일괄 매도**(9.3) 또는 감시 화면의 수동 매도로 진행하십시오.

> ⚠️ 권리이벤트로 중지된 종목은 **자동매매를 재개할 수 없습니다.** 분할·병합 이후 평균단가가 변경 전 기준으로 남아 있어, 재개하는 순간 잘못된 기준으로 손절·익절이 즉시 발동하기 때문입니다. 컨텍스트 메뉴의 "선택 종목 자동매매 재개"를 실행하면 사유와 대안을 안내하는 창이 표시됩니다.

📌 **참고:** 같은 **매매중지** 배지라도 사용자가 직접 멈춘 🟠 **일시중지**(4.3.2)는 언제든 재개할 수 있습니다. 색과 문구로 구분됩니다.

| **상단 지수 표시** | 화면 맨 위에 띄울 국내 업종지수를 고릅니다. (4.5) |

### 9.1.2 매매

**예전에 매매 설정 프로필의 "기타 설정" 탭에 있던 항목들이 이곳으로 옮겨졌습니다.** 프로필마다 따로 두지 않고 **모든 전략에 함께 적용**됩니다.

💡 **왜 옮겼나:** 프로필마다 다르게 두면 같은 장에서 어떤 종목은 청산되고 어떤 종목은 남는 이유를 되짚을 수 없습니다. 당일 청산이나 재매수 제한은 특정 전략이 아니라 **그날의 운용 방침**에 가까운 항목이라 한곳에서 정하도록 했습니다.

⚠️ **공통 값은 기본값(모두 꺼짐)으로 시작합니다.** 프로필마다 값이 달랐을 수 있어 무엇을 공통값으로 삼을지 정할 방법이 없었기 때문입니다. **이 기능들을 쓰고 계셨다면 이곳에서 다시 지정해 주십시오.** 업데이트 후 첫 실행 때 안내 창이 한 번 뜹니다. (프로필에 저장돼 있던 기존 값은 지우지 않고 보관하지만 매매에는 쓰이지 않습니다.)

| 항목 | 내용 |
|---|---|
| **조건검색 시세 기준** | 통합시세(KRX+NXT) / KRX 시세. **재시작 후 적용** (7.1) |
| **당일 매수 종목 무조건 당일 청산** | KRX 종목의 매도 시점·주문 종류·호가 조정을 지정합니다. |
| **NXT 거래 가능 종목은 따로 청산** | NXT 종목의 청산 시점을 별도로 지정합니다. (아래 참고) |
| **당일 매도(청산)된 종목 재매수 제한** | **계좌별로 판정합니다.** A계좌에서 청산한 종목이라도 B계좌에서는 매수될 수 있습니다. |
| **매수·매도 미체결 자동 취소** | 지정한 초(N초) 경과 후 자동 취소 |
| **하이브리드 모드** | 기본 켜짐. 외부보유 종목을 감시 목록에 표시합니다. (4.3.1) |
| **프리/애프터마켓 지정가 변환** | 매수·매도 각각의 변환 방식과 호가 조정값 (6.1) |

**NXT 종목 분리 청산** — KRX 정규장은 15:20에 끝나지만 NXT에서 거래되는 종목은 저녁 8시까지 팔 수 있습니다. 어떤 종목이 NXT 거래 가능인지는 매일 아침 받아오는 전종목 정보로 **자동 판별**됩니다.

*   NXT 시점은 **15:40~19:50 사이를 권장**합니다. NXT는 15:40~20:00에 단독으로 거래되며, 세션 막판에는 유동성이 얕아 체결이 어려울 수 있습니다.
*   전종목 정보를 아직 받지 못한 종목은 안전하게 **KRX 시점에 청산**합니다.
*   옵션을 켜지 않으면 모든 종목이 한 시점에 청산됩니다.

📌 **참고:** 이 항목들은 **전략을 가동한 상태에서도 변경**할 수 있고 저장 즉시 반영됩니다. 다만 당일 청산을 켜거나 시각을 바꿀 때, 재매수 제한을 끌 때는 바로 주문이 나갈 수 있어 **확인을 한 번 받습니다.** 이 프로그램이 관리하지 않는 주문(HTS 등)은 자동 취소 대상이 아닙니다.

### 9.1.3 손익 계산

평가손익·실현손익·매매 통계를 **"지금 팔면 실제로 손에 남는 금액"** 기준으로 표시합니다.

⚠️ **표시되는 손익에만 영향을 줍니다.** 손절·익절·트레일링 등 **주문 발동 조건은 종전대로 체결가 기준**으로 판단하며 이 설정의 영향을 받지 않습니다.

| 묶음 | 항목 |
|---|---|
| **위탁수수료 — KRX** | 코스피·코스닥 매수/매도 수수료율 (%) |
| **위탁수수료 — NXT** | 넥스트레이드 매수/매도 수수료율 (%) |
| **제세금** | 제세금률 (%) · ETF 제세금 면제 계산 |

*   요율은 증권사·계좌마다 다르므로 **실제 적용 요율을 입력**하십시오. 0을 입력하면 해당 항목을 반영하지 않습니다.
*   프리마켓·애프터마켓 주문은 NXT로만 나가므로 **NXT 요율**이 적용됩니다. 정규장 통합(SOR) 주문은 어느 거래소에서 체결됐는지 알 수 없어 KRX 요율로 계산합니다.
*   **ETF는 제세금 면제로 계산**이 기본 켜짐입니다. 끄면 실제보다 손익이 낮게 표시됩니다.

⚠️ **제세금 기본값이 0.20% 입니다.** 2026년 1월 1일부터 매도 시 세금이 코스피·코스닥 모두 합계 **0.20%** 로 인상되었습니다(코스피: 증권거래세 0.05% + 농어촌특별세 0.15% / 코스닥: 증권거래세 0.20%). 종전 기본값 **0.15%를 그대로 쓰고 계셨다면 자동으로 0.20%가 됩니다.** 직접 다른 값을 넣어 두셨다면 그 값은 유지됩니다. 항목 이름도 "증권거래세율"에서 **"제세금률"** 로 바뀌었습니다.

📌 **참고:** 증권사는 **주문 한 건마다** 수수료·세금의 원 미만을 잘라 청구합니다. 이제 주문 건별로 계산해 합산하므로 실제 청구액과의 차이가 줄었습니다. 분할 매수·매도가 많을수록 차이가 컸던 부분입니다.

### 9.1.4 안전장치

| 항목 | 내용 |
|---|---|
| **하드 리밋 활성화** | 무한 매수/매도 차단의 마스터 스위치 |
| **반복 주문 한도 (회)** · **반복 감시 시간창 (분)** | 시간창 내 동일 종목·동일 방향 주문 횟수 제한. 0 = 무제한 |
| **이상 시세 가드** | 상하한가 이탈·0원 지정가 주문을 전송 직전에 거부 |
| **자동매매 중지 괴리율 (%)** | 기본 30. 0을 입력하면 ⚠ 경고만 표시 (8.3) |

한도 도달 시 해당 주문이 차단되고 텔레그램 알림이 발송됩니다.

> 일일 매수/매도 한도, 종목별 매수 한도, 1회 주문 최대 금액, 일일 매수 금액 한도, 잔고 최대 종목수 제한은 **계좌별 설정**입니다. 계좌 AppKey 설정 창에서 지정하십시오. (2.3 참조)

⚠️ **반복 주문 한도를 너무 낮게 잡지 마십시오.** 분할 매도처럼 정상적인 연속 주문이 한도에 걸리면 해당 포지션이 오류 상태로 남을 수 있습니다.

### 9.1.5 데이터·진단

| 항목 | 내용 |
|---|---|
| **계좌현황 동기화 주기 (초)** | 증권사 계좌의 실제 값으로 기준을 다시 맞추는 주기. 외부보유 종목의 현재가도 이때 갱신됩니다. |
| **종목정보 캐시 새로고침 시각** | 기본 07:40. 이 시각에 전종목 정보를 갱신하고 권리이벤트를 점검합니다. (8장) |
| **실시간 조건 판단 로그 기록** | 손절/익절/트레일링/분할 판단 결과를 로그로 남깁니다. |
| **테스트 모드** | 메뉴에 조건검색 가상 신호 생성기를 표시합니다. (7.3) |

📌 **참고:** 계좌현황의 평가손익·총자산 **표시 자체는 동기화 주기와 무관하게 3초마다** 갱신됩니다. 주기를 짧게 잡을수록 키움 API 호출이 비례해 늘어나므로 요청 한도에 유의하십시오.

⚠️ **실시간 조건 판단 로그**는 종목당 초당 수십~수백 건이 기록될 수 있어 **진단 목적으로만** 권장합니다.

## 9.4 프로그램 실행 스케줄

![프로그램 실행 스케줄 화면](/images/manual-lite/schedule.png)

자동 실행 시작/종료 시간과 요일을 지정합니다(07:30~23:00 범위). Windows 작업 스케줄러를 사용하므로 등록 시 관리자 권한이 필요하며, 종료 시각에는 프로그램이 스스로 정상 종료합니다.

## 9.5 설정 내보내기 / 가져오기

전략·프로필 등의 설정을 파일로 내보내고 가져올 수 있습니다.

## 9.6 로그 파일 관리자

![로그 파일 관리 화면](/images/manual-lite/log-manager.png)

로그 보관 기간을 설정하고, 파일 목록(크기·수정일)을 확인하거나 메모장으로 열고 삭제할 수 있습니다. 문제 진단이 필요할 때 **로그 파일을 서버로 전송**할 수 있습니다.

> 라이트 버전은 매매·시세용 외부 서버와 연동하지 않으며, 이 기능은 진단 목적의 로그 업로드에 한정됩니다.

## 9.7 키움 접속이 막혔을 때 (IP 변경)

키움은 **미리 등록한 인터넷 IP에서만** 접속을 허용합니다. 그런데 가정집 인터넷은 IP가 수시로 바뀝니다. 공유기를 껐다 켰거나 통신사가 IP를 새로 배정하면 **어제까지 되던 접속이 갑자기 막힐 수 있습니다.**

접속이 거부되면 화면 상단에 **빨간 경고 줄**이 나타나고, 누르면 안내 창이 열립니다.

| 안내 창 내용 | 설명 |
|---|---|
| **마지막 정상 접속 IP** | 직전에 접속에 성공했던 IP |
| **지금 접속하는 IP** | 현재 이 PC가 쓰고 있는 IP |

두 값이 다르면 IP가 바뀐 것이 원인입니다. **새 IP를 키움 홈페이지에 등록한 뒤 [다시 연결]** 을 누르면 됩니다.

*   **텔레그램 알림도 함께 발송**됩니다. 자동 시작으로 무인 운영 중이더라도 폰으로 알 수 있습니다.
*   인터넷 자체가 끊긴 경우에는 IP 안내 대신 인터넷 확인을 안내합니다.
*   프로그램이 **30분마다 IP 변경을 미리 확인**합니다. ([시스템 설정 → 표시]의 접속 IP 변경 감시, 기본 켜짐)

📌 **참고:** 감시를 꺼도 실제로 접속이 거부됐을 때의 안내는 그대로 동작합니다. IP 확인에는 외부 조회 서비스를 사용합니다.


# 10. 텔레그램 알림

라이트 버전은 매매 알림을 **텔레그램**으로 전송합니다. (Discord는 지원하지 않습니다.) **설정 → 텔레그램 알림 설정**에서 구성합니다.

![텔레그램 알림 설정 화면](/images/manual-lite/telegram-setting.png)

| 항목 | 내용 |
|---|---|
| **텔레그램 알림 사용** | 알림 전송 On/Off |
| **알림 종류** | 받을 메시지를 체크박스로 선택합니다 — **체결**, **포지션 생성/청산**, **주문 취소**, **오류/경고** |
| **Bot Token** | @BotFather에서 발급받은 봇 토큰 (예: 123456:ABC-DEF...) |
| **기본 Chat ID** | 계좌별 Chat ID가 없을 때 사용하는 기본 수신처 |
| **계좌별 개별 Chat ID** | 계좌마다 다른 채널로 알림 수신 (실서버/모의투자 구분, 계좌별 테스트 전송) |

*   Bot Token은 텔레그램에서 **@BotFather**로 봇을 만들면 발급되고, Chat ID는 **@userinfobot**으로 확인할 수 있습니다.
*   **기본 테스트 전송** 버튼으로 연결을 확인합니다.

📌 **참고:** 위 알림 외에 **하드 리밋 차단**(9.1.4), **권리이벤트 자동매매 중지**(8.3), **키움 접속 거부**(9.7)도 텔레그램으로 통지됩니다.


# 11. 부록

## 11.1 실시간 등록 한도

키움 API 제한에 따라 계좌별로 실시간 등록 건수가 제한됩니다. 하단 상태바의 실시간 등록 현황을 클릭하면 현재 사용량과 한도(체결 데이터 최대 100건, 조건검색 최대 10건 등)를 여유·주의·포화 색상으로 확인할 수 있습니다.

## 11.2 키움 접속 단절 시간

월~토 07:50~07:55, 일 05:00~05:15에는 키움 서버 접속이 일시적으로 끊깁니다. 이 시간에는 주문·조회가 제한됩니다. 이 시간에 프로그램을 시작하면 연결 지연 안내 창이 뜨고 **점검 종료까지 남은 시간이 실시간으로 표시**됩니다.

## 11.3 주문 전송 속도 제한

키움 API의 주문 유량 한도에 맞춰 프로그램이 자동으로 전송 속도를 조절합니다. 한도는 서버 구분에 따라 다르며, **모의투자 서버는 초당 1건**으로 실서버보다 낮습니다. 모의투자에서 짧은 간격으로 여러 종목이 포착되면 주문이 순차적으로 지연 전송될 수 있습니다.

## 11.4 버전 정보

본 설명서는 부엉이 트레이더 라이트 **v1.5.1** 기준으로 작성되었습니다. 프로그램의 현재 버전은 제목 표시줄에서 확인할 수 있습니다.
